# Creative Activity Tracker
創作活動の記録を管理し、日々の積み重ねを可視化するWebアプリです。

# アプリの概要
創作活動を継続するために、日々の活動を記録し、ゲームのような成長要素を通じてモチベーションを維持することを目的に制作しました。

## スクリーンショット
![Creative Activity Tracker](images/screen.png)

# 主な機能
・創作活動の記録

・経験値（EXP）による成長要素

・レベルアップ通知

・実績解除と報酬の表示

・目標と締め切り管理

・活動記録の統計管理

## 制作で工夫した点
